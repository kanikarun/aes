# Odoo Website

## Introduction

A frontend for Odoo Website using [Next.js](https://nextjs.org/).

## Installation

```bash
yarn install
```

## Running the app

Create `.env` file from `.env.example` and set environment variables before you run the service.

```bash
# Start on development mode
yarn dev

# Build production-ready app
yarn build

# Start application
yarn start
```

Command to check your files format and other helper.

```bash
# Check rules & format files command
yarn lint
yarn format

# Check for missing and broken translations
yarn i18n:check

# Check dependencies version
yarn run upgrade
```
