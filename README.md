# Odoo Website

## Introduction

Repositories for Odoo Website with [Strapi](https://docs.strapi.io/) as backend and [Next.js](https://nextjs.org/) as frontend.

## Installation

Go into one of directories, [Backend](/backend) or [Frontend](/frontend) then:

```bash
$ yarn install
```

## Running the app

Create `.env` file from `.env.example` and set environment variables before you run the service.

```bash
# Start in development mode
$ yarn dev

# Build production-ready
$ yarn build

# Start running the application
$ yarn start
```
